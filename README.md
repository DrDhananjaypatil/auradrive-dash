# AuraDrive Dash

Car-screen dashboard for AuraDrive: speed dial with speed-limit warning, clock, live weather, trip stats, compass, quick app links, and a built-in music player (your own songs plus internet radio). Four looks to choose from in Settings: Aura, Sport, Electric and Retro.

Live at https://drdhananjaypatil.github.io/auradrive-dash/

Open it in the car stereo's browser or AuraDrive's Browser and allow location for live speed, trip and weather.
